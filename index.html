場所を調べ、移動し、フォルダとファイルを作り、中身を読むところまで自分の手で進めました。

  • pwd / ls / cd — 場所を確かめて移動する
  • mkdir / touch — フォルダとファイルを作る
  • cat — ファイルの中身を読む

ターミナルはそのまま自由に試せます。迷ったら help で使えるコマンドを確認できます。
