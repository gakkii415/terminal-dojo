# terminal-dojo

コマンドラインをゼロから対話的に学べる、日本語の初心者向けWebアプリです。

## 現在地

要件・教材範囲・UI方向性・最小構成まで確定済みです。アプリコードはまだありません。次の工程で初期完成版を実装します。

## 中心価値

インストールや実ファイル破損の不安なしに、説明を読んだ直後から自分でコマンドを入力し、「入力 → シェルの解釈 → 結果」を結び付けて理解できます。

## 初期完成版（MVP）

- Bash風の安全な擬似ターミナルと擬似ファイルシステム
- `pwd`、`ls`、`cd`、`mkdir`、`touch`、`cat` を扱う5レッスン
- 正解文字列ではなく、実行後のファイルシステム状態で課題を判定
- 初心者向けのエラー説明、段階ヒント、コマンド履歴
- 進捗のlocalStorage保存、レッスン単位／全体のリセット
- Desktop中心、Mobileでも主要フローを完了できるレスポンシブUI
- キーボード操作、可視フォーカス、reduced motion対応

## 今回の非対象

- 実OS・コンテナ・VMへの接続
- バックエンド、DB、認証、クラウド同期
- AIチャット、課金、ランキング、共有
- `rm` などの削除系、権限、パイプ、リダイレクト、シェルスクリプト
- GitHub Pages公開と本番運用

## 実装方針

依存関係とファイル数を増やさず、HTML・CSS・JavaScript・教材データを `index.html` にまとめた静的Webアプリとして始めます。コマンドは許可リスト型のシミュレーターで処理し、ブラウザや利用者の実ファイルには触れません。

## リポジトリ構成

現在は実装前文書のみです。次の工程で `index.html` を1ファイル追加します。

```text
terminal-dojo/
├── index.html          # 次工程で追加するアプリ本体（未作成）
├── README.md           # 概要・MVP範囲・構成
├── AGENTS.md           # プロジェクト共通指示
├── WORKFLOW.md         # 開発・改善の工程
├── FEATURES.md         # 機能と状態の恒常判断
├── CONTENT.md          # 教材構成と品質基準
├── DESIGN.md           # UI/UXと視覚方針
└── DESIGN_REVIEW.md    # 実装完了後の独立レビュー基準
```

## 次の工程

`index.html` に初期完成版を実装し、5レッスンの入口から完了までを通して確認します。完成後はいったん停止し、実画面レビューへ進みます。
