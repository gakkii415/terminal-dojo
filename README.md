# Terminal Dojo

コマンドラインをゼロから対話的に学べる、日本語の初心者向けWebアプリです。

## 現在地

初期完成版を実装済みです。5レッスン・全10チャレンジを、実環境を壊す心配のないブラウザ内シミュレーターで最後まで学べます。

## 公開ページ

https://gakkii415.github.io/terminal-dojo/

## 起動方法

依存関係やビルドはありません。リポジトリのルートで次を実行します。

```bash
python3 -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開いてください。`index.html` を直接開いても基本機能は動作します。

## 学べること

- `pwd` で現在地を確認する
- `ls` でファイルとフォルダを見る
- `cd` と `..` で場所を移動する
- `mkdir` と `touch` でフォルダとファイルを作る
- `cat` でファイルの中身を読む
- 相対パス、絶対パス、`.`、`..` の関係を理解する

## 学習体験

- Bash風の安全な擬似ターミナルと擬似ファイルシステム
- 正解文字列ではなく、実行後の場所や生成物を使う状態ベース判定
- command / argument / resolved path / result を追える「コマンド分解トレース」
- 「起きたこと・確認・次に試す」で示す初心者向けエラー説明
- 観察ポイントから入力例までを1段階ずつ開く3段階ヒント
- 上下キーの入力履歴、`Ctrl+L` の画面クリア
- `localStorage` による進捗復元
- レッスン単位と全体の確認付きリセット
- Desktop中心、Mobileでは課題を下端シートへ再構成するレスポンシブUI

## 安全性とデータ

許可リストにあるコマンドだけをJavaScriptで解釈します。実OS、利用者の端末、実ファイル、サーバーへは接続しません。進捗と擬似ファイルシステムは、このブラウザの `terminal-dojo:v1` キーにだけ保存します。

## 検証済み

- 全10チャレンジの入口からコース完了まで
- 存在しないパス、型違い、引数違い、未対応コマンドのエラー表示
- 3段階ヒント、入力補助、上下キー履歴
- 再読み込み後の進捗・現在地・擬似ファイル復元
- レッスン単位／全体リセット
- Desktop 1280 × 720、Mobile 390 × 844
- JavaScript構文確認、可視フォーカス、reduced motion

## 今回の非対象

- 実OS・コンテナ・VMへの接続
- バックエンド、DB、認証、クラウド同期
- AIチャット、課金、ランキング、共有
- `rm`、権限、パイプ、リダイレクト、シェルスクリプト

次の拡張は先に決めず、初心者による実利用で詰まり方を確認してから選びます。
